## 4. 实测发现（已处理）
1. **参考 `kmeans_pytorch.kmeans` 在 NaN 输入下无限循环**（`while True` 直到 `center_shift**2 < tol`，NaN 永不满足）。原因：特征/坐标归一化在常量维度上 0/0。处置：运行时守卫（非有限输入即失败 + 静音 tqdm），**不修改上游源码**。
2. **参考 `get_keypoints` 跨调用不确定**：仅在 `__init__` 里设种子，而 kmeans 用全局 RNG。处置：调用前重设 `np/torch` 种子（本机 R1 据此断言可复现；节点也应如此）。
3. **`utils.py` 顶层 import `open3d`**，即使只用 `filter_points_by_bounds` 也需要装 open3d。已装。
4. **参考 IK 依赖 OmniGibson/Lula**；以确定 IK 桩替代即可跑通 solver（MuJoCo env 将提供自己的 IK）。
