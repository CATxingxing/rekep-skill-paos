## 4. 配置 ReKep VLM 密钥（不写入仓库）

Dora 不会把启动 shell 的环境变量透传给节点，因此节点改为在启动时读取外部 `service.env`：

```bash
SD="$HOME/.PhyAgentOS/run/rekep-sim"; mkdir -p "$SD"
printf 'REKEP_VLM_BASE_URL=https://newapi.x-era.com/v1\nREKEP_VLM_MODEL=deepseek-v4-flash-vision-exp\nREKEP_VLM_API_KEY=%s\n' "$XERA_API_KEY_1" > "$SD/service.env"
chmod 600 "$SD/service.env"
```

- 该模型必须用 `$XERA_API_KEY_1`（`$XERA_API_KEY_2` 返回 403）；密钥仅落在 `/data7` 外部文件，不入库。
- 节点侧加载逻辑：`src/rekep_sim/state.py::load_service_env()`，三节点 `main()` 首行调用。

## 9. 契约与异常场景验收命令（对应《参考手册》§1.4 / §5.2）

```bash
# §1.4-1 归档 sha256/size 与 lock 一致；§1.4-2 单文件 Node + 回执
for a in dist/nodes/*.tar.gz; do echo "$(sha256sum "$a"|awk '{print $1}')  $(basename "$a")"; done
for a in dist/nodes/*.tar.gz; do tar -tzf "$a"; done
find "$HOME/.PhyAgentOS/forge_runtime/nodes" -name '.paos-node.json'
sha256sum dist/skills/rekep-sim-0.1.0.tar.gz; stat -c%s dist/skills/rekep-sim-0.1.0.tar.gz

# §1.4-5/6 start 后 Tool ready；stop 后无残留
$P skill status rekep-sim
$P skill stop rekep-sim --force; sleep 3; pgrep -f 'rekep_(perception|plan|execute)' | wc -l

# §5.2 篡改 bundle（保留原 manifest）→ 必须拒绝且旧版本保留
B=$(ls -t dist/skills/rekep-sim-0.1.0.tar.gz|head -1)
T=$(mktemp -d /data7/home/linjiongxiao/.tmp/opencode/tamper.XXXX)
tar -xzf "$B" -C "$T"; printf '\n# TAMPERED\n' >> "$T/SKILL.md"
( cd "$T" && tar -czf "$T/tampered.tar.gz" archive-manifest.json SKILL.md skill.yaml profiles assets )
$P skill install "$T/tampered.tar.gz" --local --yes
$P skill inspect rekep-sim

# §5.2 PATH 缺少 dora → start 必须报错
env -i HOME="$HOME" PATH=/usr/bin:/bin "$PAOS_ENV/bin/python" scripts/paos_dev_shim.py skill start rekep-sim --profile sim

# 视频真实性（帧数/时长）
for f in red_cube_to_red_region_vlm_plan_9365ebb9 blue_cube_to_blue_region_vlm_plan_630b8b42 red_on_blue_vlm_plan_f23e6c72 pen_upright_in_holder_vlm_plan_6ad90e9e; do
  ffprobe -v error -select_streams v:0 -count_frames -show_entries stream=nb_read_frames -show_entries format=duration -of csv=p=0 "$HOME/.PhyAgentOS/workspace/artifacts/rekep-sim/$f.mp4"
done
```
