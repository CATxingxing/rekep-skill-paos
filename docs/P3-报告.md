## 3. 关键问题与修复（本机踩坑记录）
1. **共享主机的 Dora 端口冲突**：其他用户占用 6012/53290/53291，PAOS 的 `dora check` 误判为已就绪，`dora start` 连到别人的 coordinator，spawn 失败。修复：用 `unshare -rn` 私有网络命名空间隔离整个栈（`scripts/nsrun.sh`）。
2. **glibc 2.31 的 `chmod(follow_symlinks=False)`**：PAOS 安装/解包需要 shim（`scripts/shim/sitecustomize.py`）。
3. **gateway v1.1.0 拒绝 `agent` 配置键**（旧配置遗留）→ 删除。
4. **`forge_tool` 约束**：session operation 不可 `cancellable`、必须 `stoppable`+`status_supported`；action 不可 `stoppable`。
5. **execute node 过早重初始化**（solver warmup ~90s）导致 dataflow 启动延迟、PAOS 健康检查超时 → 改为**惰性初始化**。
6. **IK 不可达/坏种子** → 多 seed 鲁棒 IK + 固定 tool-down 姿态。
7. **assisted grasp 缺失** → 参考实现用 OmniGibson assisted grasping，MuJoCo 下以附着近似。
